# 🚀 TalentSync AI

> AI-Powered Recruitment Platform

TalentSync AI is a modern AI-powered recruitment platform that helps candidates apply for jobs faster while helping recruiters identify the best candidates using AI-powered resume analysis and candidate matching.

---

# Features

## Candidate

- Authentication
- Upload Resume
- AI Resume Parsing
- AI Candidate Summary
- Browse Jobs
- Smart Job Search
- Apply to Jobs
- Track Application Status
- Dashboard

## Recruiter

- Recruiter Dashboard
- Create Jobs
- Edit Jobs
- Delete Jobs
- View Applicants
- AI Candidate Summary
- AI Match Score
- Shortlist Candidates
- Analytics Dashboard
